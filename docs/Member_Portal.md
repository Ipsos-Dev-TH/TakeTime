# Member Portal — บัตรสมาชิก + ส่วนลดตามวันเข้าพัก + Voucher

## ฝั่งสมาชิก (ลูกค้า)

**เข้าที่เมนู "สมาชิก" บนหน้าเว็บ** (`/Member/Login`) — มือถือใช้สะดวก

- **ล็อกอิน**: เบอร์โทร + PIN — เข้าครั้งแรกใช้ **เลขท้ายเบอร์ 4 ตัว** แล้วระบบบังคับตั้ง PIN ใหม่ทันที
  (ใส่ผิด 5 ครั้ง = ล็อก 10 นาที · ลืม PIN → พนักงานรีเซ็ตได้)
- **หน้าบัตร** (`/Member/Card`):
  - บัตรสมาชิกสวย ๆ — ใช้**รูปหน้าบัตรของ tier** (ตั้งได้) หรือพื้นไล่สีตามสี tier อัตโนมัติ
  - ชื่อ · เบอร์ (ปิดบางส่วน) · **เลเวล** · สมาชิกตั้งแต่ · แต้มสะสม · **วันหมดอายุบัตร**
    (หมดอายุ = ขึ้นแถบ "หมดอายุ" ทับบัตร และสิทธิ์ส่วนลดหยุดทำงาน)
  - **ส่วนลดค่าห้องของระดับตัวเอง**: วันธรรมดา X% / วันหยุด Y%
  - สิทธิพิเศษอื่นของ tier (จาก Loyalty_Tier_Benefits เดิม)
  - **คูปองของฉัน**: กด "ใช้คูปอง" → โชว์**โค้ดตัวใหญ่** (เช่น `DRK-7K4MX`) ให้พนักงาน
    ภายในเวลาที่กำหนด (ตั้งได้ต่อคูปอง เช่น 60 นาที) — ปล่อยหมดเวลา = โค้ดพับกลับ กดใช้ใหม่ได้

## ฝั่งพนักงาน

**ลูกค้า & การตลาด → Voucher & สิทธิ์สมาชิก** (`/Admin/CRM/MemberVouchers`)

1. **แลกคูปอง** (บนสุด — งานหน้าเคาน์เตอร์): พิมพ์โค้ดจากมือถือลูกค้า + บันทึกเช่น "ลาเต้เย็น" → แลก
   ระบบตรวจครบ: โค้ดจริง / ลูกค้ากดใช้แล้ว / ไม่หมดเวลา / ไม่ถูกใช้ซ้ำ (กันใช้พร้อมกัน 2 เครื่อง)
2. **ส่วนลดค่าห้องตามวันเข้าพัก**: ตาราง tier × (วันธรรมดา % | วันหยุด %) — "วันหยุด" = ส-อา +
   วันที่ตั้งราคาพิเศษในหน้า ราคาวันหยุด
3. **แบบคูปอง (template)**: ชื่อ + **เงื่อนไขอิสระ** (เช่น "เครื่องดื่มในคาเฟ่เท่านั้น ไม่รวมของขาย")
   + โค้ดขึ้นต้น + อายุคูปอง (วัน) + เวลาโค้ดหลังกดใช้ (นาที) + เปิด/ปิด
4. **แจกคูปอง**: รายคน (เบอร์) หรือ**ทั้งระดับ** (กันแจกซ้ำคนที่มีใบเดิมค้างอยู่ อัตโนมัติ)
5. **Tracking**: ประวัติคูปองล่าสุด — โค้ด/สมาชิก/สถานะ/ใครแลก/เมื่อไหร่/บันทึก

## วงจรสถานะ voucher

```
ISSUED (แจกแล้ว) ──ลูกค้ากดใช้──▶ ACTIVATED (โค้ดโชว์ มีเวลาจำกัด) ──พนักงานแลก──▶ REDEEMED
      ▲                               │ หมดเวลาโค้ด
      └───────────────────────────────┘  (กลับมา กดใช้ใหม่ได้)
   เลย Expiry_Date → EXPIRED
```

โค้ดใช้ตัวอักษรที่ไม่สับสน (ตัด 0/O, 1/I/L) — ลูกค้าอ่าน พนักงานพิมพ์ตามได้ไม่ผิด

## นักพัฒนา

- `MemberPortalService.GetRoomDiscountPct(phone, checkinDate)` — % ส่วนลดของสมาชิกสำหรับวันนั้น
  (คืน 0 ถ้าไม่ใช่สมาชิก/บัตรหมดอายุ) — พร้อมให้หน้าจองเรียกใช้ในอนาคต
- รูปหน้าบัตร: ใส่ path ที่ `Loyalty_Tiers.Card_Image_Path` (แนะนำ 856×540 หรืออัตราส่วนบัตรเครดิต)
- ตาราง: `Loyalty_Tier_Room_Discounts`, `Member_Voucher_Templates`, `Member_Vouchers`
  + คอลัมน์ใหม่ใน `Customer_Loyalty` (PIN hash, Membership_Expiry) — ทั้งหมดใน **PHASE18_25**
  ไม่แตะแต้ม/การเลื่อน tier เดิม

## สิ่งที่ยังไม่ทำ (บอกตรง ๆ)

- ส่วนลดสมาชิก**ยังไม่หักอัตโนมัติ**ในหน้าจอง — สมาชิกโชว์บัตร/พนักงานเห็นเกณฑ์แล้วให้ส่วนลดเอง
  (helper พร้อมแล้ว ถ้าจะให้หักอัตโนมัติในหน้า Reserve บอกได้ — แตะเรื่องเงินจึงแยกไว้ก่อน)
- วันหมดอายุสมาชิกตั้งผ่าน SQL/หน้าจัดการสมาชิกเดิม (`Customer_Loyalty.Membership_Expiry`) —
  ยังไม่มีช่องแก้ใน UI ใหม่
